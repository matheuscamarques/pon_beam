PON-BEAM

Uma Máquina Virtual Orientada a Notificações

Matheus de Camargo Marques

Sobre este livro

A PON-BEAM é uma re-arquitetura da máquina virtual BEAM usando o Paradigma Orientado a Notificações (PON) de Jean Marcelo Simão. Cada subsistema interno da VM — scheduler, selective receive, timer wheel, ETS, garbage collector — é redesenhado como uma entidade PON reativa.
